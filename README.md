# Math Arcade - Educational Teaching Platform

A modern, interactive educational platform designed to teach mathematics through engaging lessons and games. Built with HTML, CSS, and vanilla JavaScript.

## Features

- 🎓 **Interactive Lessons** - Comprehensive math lessons covering arithmetic, geometry, and algebra
- 🎮 **Engaging Games** - Quick Math game and other interactive challenges
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- ✨ **Modern UI** - Beautiful gradient design with smooth animations
- 🚀 **Fast & Lightweight** - Pure HTML/CSS/JS, no dependencies

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/shawnbourque-beep/file-C-Users-sbour-Downloads-Mr.-20Bourque-E2-80-99s-207th-20Grade-20Math-20-5-.html-arcade.git
cd file-C-Users-sbour-Downloads-Mr.-20Bourque-E2-80-99s-207th-20Grade-20Math-20-5-.html-arcade
```

2. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

3. Navigate to `http://localhost:8000` in your browser

## Customization

### Colors
Edit the color scheme in `styles.css`:
- Primary gradient: `#667eea` to `#764ba2`
- Accent color: `#ffd700`

### Content
Modify the HTML structure in `index.html` to add:
- New lesson cards
- Additional games
- Custom content sections

### Games
Add new games by creating new JavaScript functions in `script.js` and linking them to buttons in `index.html`
